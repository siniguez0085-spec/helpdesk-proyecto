# Help Desk UI Kit

## Descripción

Este proyecto corresponde al desarrollo de una Librería de Componentes UI (UI Kit) para el sistema Help Desk de la asignatura Desarrollo de Sistemas Informáticos.

## Componentes desarrollados

- Botones
  - Primario
  - Secundario
  - Peligro

- Formularios
  - Input
  - Select

- Tarjetas (Cards)

- Badges
  - Alta
  - Media
  - Baja

- Alertas
  - Éxito
  - Advertencia
  - Error

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Variables CSS
- Media Queries
